Ubuntu Commands-Network Investigation

Ip -br addr   (ip address-brief format)
To check whether ubuntu had an ip address assigned to it's network interface (ens33)
Used ip -br addr to inspect the Ubuntu network interface and verify its IP address. Initially, the interface had no IPv4 address. After troubleshooting, we confirmed that 192.168.50.30/24 was successfully assigned.

ip route  (ip routing table)
This tells Ubuntu:
- 192.168.50.0/24 — Destination network.
- dev ens33 — Use this network interface.
- src 192.168.50.30 — Use this as the source IP.
Used ip route to inspect the routing table and verify how Ubuntu reaches other devices in the 192.168.50.0/24 network.

ip neigh (IP neighbor table.)
When Ubuntu communicates with another device in its local network, it needs that device's MAC address.
Used ip neigh to inspect the neighbor table and verify IP-to-MAC address mappings. This helped us investigate whether Ubuntu could discover other devices on the local network.

nmcli device status  (NetworkManager Command-Line Interface — device status.)
Ubuntu uses NetworkManager to manage network connections.
Used nmcli device status to inspect the connection state of Ubuntu's network interface. This helped identify that ens33 was disconnected and verify that it was successfully reconnected.
